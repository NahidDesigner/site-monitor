How often should the CSS check run?

The breakage this catches heals itself once the cache refreshes, so the schedule decides how much of it you see. Every 6 hours is a reasonable start. Tighten it if breaks turn out to be short-lived; loosen it if runs get expensive — a full check is roughly 15 requests per page, so the cost scales with how many pages you watch.
